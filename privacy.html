Privacy Policy

Grab2Sheet
Last updated: September 29, 2026

Summary: Grab2Sheet processes webpage extraction locally in Chrome. The current release does not require an account and does not upload extracted datasets to Grab2Sheet servers.

1. What Grab2Sheet does

Grab2Sheet is a Chrome extension that helps users extract structured information from webpages, preview and clean the extracted information, and export it to spreadsheet formats such as Microsoft Excel (.xlsx), CSV, or the clipboard.

2. Webpage access and host permissions

Grab2Sheet declares access to HTTP and HTTPS webpages because accessing webpage content is necessary for its core function. The extension needs to inspect the webpage that the user chooses to process in order to detect tables, repeating cards, product listings, job listings, property listings, directories, links, images, and other structured information.

These host permissions allow Grab2Sheet to perform extraction reliably when the user invokes the extension and interacts with its side-panel interface.

Webpage access is used only for Grab2Sheet's extraction, preview, cleanup and export functionality.

Grab2Sheet does not use webpage access for advertising, browsing-history tracking, behavioral profiling, background surveillance, or unrelated monitoring.

3. Scripting permission

Grab2Sheet uses Chrome's scripting permission to run its packaged extraction code on webpages. This allows the extension to inspect webpage structure and identify data that can be converted into spreadsheet rows and columns.

The JavaScript used for this functionality is included inside the Grab2Sheet extension package.

4. Side panel

Grab2Sheet uses Chrome's side panel to display the extraction interface beside the webpage being processed.

The side panel allows users to select detected datasets, preview extracted rows, choose columns, reorder or rename fields, remove duplicate or empty rows, and export the resulting dataset.

5. Website content

Grab2Sheet may process website content such as visible text, links, images, table values, product information, listing information, and other webpage elements when the user chooses to extract that information.

This processing occurs for the purpose of providing the extension's extraction and export functionality.

6. Local data processing

Extracted webpage content is processed locally in the user's browser for dataset detection, preview, cleanup, deduplication, column management, and export.

The current version of Grab2Sheet does not transmit extracted datasets to Grab2Sheet servers.

7. Accounts and personal information

The current version of Grab2Sheet does not require users to create a Grab2Sheet account.

Grab2Sheet does not require users to provide their name, physical address, phone number, payment information, passwords, or authentication credentials in order to use the extension.

8. Remote code

Grab2Sheet does not download or execute remote JavaScript, WebAssembly, or other remote executable code.

The executable code used by the extension is packaged with the extension submitted to the Chrome Web Store.

9. Data sale and sharing

Grab2Sheet does not sell extracted webpage data or personal information.

Grab2Sheet does not share extracted datasets with advertising networks, data brokers, or other third parties for advertising or profiling purposes.

10. Browsing history and tracking

Grab2Sheet does not maintain a history of websites visited by the user and does not use webpage access to build browsing profiles.

Grab2Sheet does not perform keystroke logging, behavioral tracking, background browsing surveillance, or advertising tracking.

11. Data retention

Because extracted datasets are processed locally and are not uploaded to Grab2Sheet servers in the current release, Grab2Sheet does not retain server-side copies of exported datasets.

12. Third-party websites

Grab2Sheet operates on webpages selected by the user. Third-party websites have their own privacy policies, terms of service, and data practices.

Grab2Sheet is not responsible for the privacy practices of third-party websites.

13. Changes to this Privacy Policy

This Privacy Policy may be updated if Grab2Sheet's features, permissions, or data practices change.

The latest version of this policy will be published on this page.
