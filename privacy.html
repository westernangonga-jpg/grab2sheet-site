Privacy Policy

Grab2Sheet
Last updated: September 28, 2026

Summary: Grab2Sheet is designed to process webpage extraction locally in Chrome. The current release does not require an account and does not upload extracted datasets to Grab2Sheet servers.

1. What Grab2Sheet does

Grab2Sheet is a Chrome extension that helps users extract structured information visible on webpages, preview and clean that information, and export it to spreadsheet formats such as Excel (.xlsx) and CSV.

2. Webpage access

Grab2Sheet uses Chrome permissions such as activeTab and scripting to access the webpage the user explicitly chooses to process. Access is used to identify tables, repeating cards, listings, links, images, and other structured fields needed for extraction.

Grab2Sheet does not request persistent access to every website in the current release.

3. Data processing

Extracted webpage content is processed locally in the user's browser for preview, cleanup, deduplication, column management, and export.

The current release does not transmit extracted datasets to Grab2Sheet servers.

4. Accounts and personal information

The current release does not require a Grab2Sheet account. Grab2Sheet does not require users to provide their name, address, phone number, or payment information to use the extension.

5. Remote code

Grab2Sheet does not download or execute remote JavaScript, WebAssembly, or other remote executable code. The executable code used by the extension is packaged with the extension.

6. Data sharing and sale

Grab2Sheet does not sell extracted webpage data or personal information. The current release does not share extracted datasets with third-party advertising networks or data brokers.

7. Data retention

Because extracted datasets are processed locally and are not uploaded to Grab2Sheet servers in the current release, Grab2Sheet does not retain server-side copies of exported datasets.

8. Third-party websites

Grab2Sheet operates on webpages selected by the user. Those websites have their own privacy policies and terms. Grab2Sheet is not responsible for the privacy practices of third-party websites.

9. Changes to this policy

This policy may be updated if Grab2Sheet's features or data practices change. The latest version will be published on this page.

10. Contact

For privacy or support questions, contact grab2sheetsupport@gmail.com.
