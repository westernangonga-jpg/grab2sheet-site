# Grab2Sheet GitHub Pages site

Static website for Grab2Sheet.

Files:
- index.html — product homepage
- support.html — support page for Chrome Web Store
- privacy.html — privacy policy for Chrome Web Store
- styles.css — site styling
- .nojekyll — serve files directly with GitHub Pages

Recommended repository name: `grab2sheet-site`

After uploading:
1. Open GitHub repository Settings.
2. Open Pages.
3. Under Build and deployment choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`.
5. Save.

Expected URLs:
- https://YOUR-USERNAME.github.io/grab2sheet-site/
- https://YOUR-USERNAME.github.io/grab2sheet-site/support.html
- https://YOUR-USERNAME.github.io/grab2sheet-site/privacy.html
